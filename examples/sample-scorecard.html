All 26 Built-in Checks

full reference — every check's control mapping, CIS IG, and FAIR rating, not just the ones that failed this run

Each check's control mapping was individually researched against NIST SP 800-207/800-53, CIS Controls v8, ISO/IEC 27001:2022 Annex A, NIST CSF 2.0, the HIPAA Security Rule (45 CFR Part 164), PCI DSS v4.0.1, and SOC 2 (AICPA Trust Services Criteria). A framework's tag appears on a check only where a specific, citable control was confirmed — a check with no defensible match to a given framework simply has no tag for it, rather than a forced connection. HIPAA and PCI DSS in particular are scoped to ePHI and cardholder-data environments respectively, so several recordkeeping-only checks (asset ownership, hardware serials) have no mapping under those two frameworks even though they map under ISO 27001 / NIST CSF / SOC 2.
