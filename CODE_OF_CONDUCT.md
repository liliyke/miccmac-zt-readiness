# Code of Conduct

This project is committed to a harassment-free, respectful experience for
everyone, regardless of background or identity.

## Expected behaviour

- Be respectful, constructive, and patient.
- Welcome newcomers and differing viewpoints.
- Focus on what is best for the community and the project.

## Unacceptable behaviour

Harassment, discriminatory language, personal attacks, or sharing others'
private information without consent.

## Enforcement

Concerns may be raised with the maintainer via a private GitHub issue or
direct message. Reports will be reviewed and handled confidentially.

This document is adapted in spirit from the Contributor Covenant.
